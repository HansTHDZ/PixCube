# PixCube — portafolio web

Sitio estático hecho con HTML, CSS y JavaScript. No requiere instalación, compilación ni dependencias: abre `index.html` para verlo y publica esta carpeta en GitHub Pages.

## Antes de publicar

- Cambien “Integrante 01–06” y las áreas por los nombres, fotos o perfiles reales de cada persona.
- Reemplacen los visuales conceptuales por proyectos reales cuando tengan autorización para mostrarlos. El sitio ya los identifica como conceptos.
- Actualicen la descripción de servicios para reflejar exactamente lo que ofrece el equipo.
- Las fuentes usan Google Fonts y tienen alternativas del sistema; el resto del sitio se sirve localmente.

## Publicar en GitHub Pages

Suban el contenido de esta carpeta a la rama/repositorio del sitio. En GitHub, abran **Settings → Pages**, elijan **Deploy from a branch**, seleccionen la rama y la carpeta raíz (`/`). Si es un sitio de proyecto, los enlaces internos son relativos y funcionan bajo una ruta de repositorio.

## Archivos

- `index.html`: contenido y estructura.
- `styles.css`: identidad visual, diseño adaptable y animaciones.
- `script.js`: menú móvil, año automático y animaciones al entrar en pantalla.
- `assets/`: logos compartidos por el equipo.

El botón flotante alterna entre tema oscuro y claro y recuerda la elección en el navegador.
